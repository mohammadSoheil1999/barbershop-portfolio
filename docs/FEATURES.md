# Features

## Customer experience

- Account registration and approval state
- Authenticated personal appointment list
- Date and slot availability selection
- Eligibility-aware booking and cancellation
- Notification permission and reminder foundations
- Installable progressive-web-app experience where supported

## Administration

- Review and activate/deactivate customer accounts
- View and manage appointments
- Create bookings on behalf of customers
- Configure tenant name, palette, cards, and background presentation

## Platform behavior

- Shared-schema tenant isolation
- Role-aware server routes
- Multilingual, RTL-aware interface
- Responsive desktop and mobile layouts
